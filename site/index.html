为什么值得你点 Star

Termux 是黑框终端、Pydroid 装包要联网、Acode 跑不了真代码——CodePocket 把「真离线」和「现代 IDE」一起做到了手机上。

原生引擎，不是模拟

内置 CPython 3.13.9（PEP 738 官方 Android 支持），原生 ARM64 / x86_64 编译，无 WASM 降速。真文件系统、完整 traceback、input() 交互、死循环可中断——桌面 Python 能写的这里都能写。

开箱即用，装完即离线

Python 解释器与标准库随 APK 打包，首次启动秒级解压；离线包管理支持导入纯 Python 包。Git（JGit）、Markdown 预览、语法高亮全部内置，飞行模式下装上就能写。

现代 IDE 体验

多文件 Tab、全局搜索、正则计数跳转、报错行点击直达源码、自动闭合括号、行号开关、自动换行、跳行、图片预览、双指缩放字号，还有 Git 面板、命令面板与分屏预览。

0.0.34 新增：从 HTTPS 远程 Git clone（凭据不落盘）、项目 zip 导入/导出（防 Zip Slip 与体积上限）、forkpty 子进程改为 fork 前构造环境并 execve、命令子进程用 setsid 进程组回收；引擎卡死时输出栏提供「重启应用」恢复入口。0.0.33 已补 ViewModel 销毁收尾、会话流式读取、删除真实结果与 PTY 输入上限。

0.0.30：手机端遮挡治理：所有面板按键盘上方可用高度布局，标题/输入框/按钮固定，只有正文滚动；终端全屏自适应、按键条贴键盘；键盘不再误触发布局切换。

0.0.29：本地 xterm.js ANSI 终端模拟器：真 PTY + 颜色/光标/全屏重绘，vim/top/less 正常显示；移动端方向键与 Ctrl 键、亮暗双主题。
