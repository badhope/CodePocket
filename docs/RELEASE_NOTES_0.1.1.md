# CodePocket 0.1.1 — 移动端布局收口

**版本号**：0.1.1（versionCode 41）  
**发布日期**：2026-11-25  
**定位**：0.1.0 之后的第一次小步迭代。不改 Python 引擎、Git 和包安装地基，只把手机、横屏、平板、字体放大下的布局做明确。

## 这一版改了什么

- **紧凑顶栏**：宽度小于 480dp 或字体缩放 ≥1.3 倍时，顶栏只保留菜单、保存、运行/停止；预览、命令面板、调试收进「更多」下拉菜单。44dp 触控目标不再把文件名挤成一条省略号。
- **按宽度分栏**：600dp 以上，或 520dp 以上的矮横屏，编辑器与输出面板左右分栏；普通手机竖屏仍上下排布，给代码留高度。
- **抽屉收窄**：侧栏宽度按屏幕宽度夹在 200–272dp；窄屏上不会吃掉主界面。
- **快捷动作换列**：窄屏/大字号从四列改成三列，避免两字标签被压成省略号。
- **小屏标题减法**：宽屏才显示语言名和「仅编辑」；小屏只保留文件名，仍单行省略。

## 明确边界

- **仍无 ARM64 真机验收**：Robolectric 只能证明节点存在与交互路径，不等于各 ROM 上的最终手感；本版不生成假截图。
- 不做 Gradle/Java/Kotlin 工程构建、完整 LSP、原生 wheel ABI；边界与 0.1.0 相同。
- 这不是“全部功能补齐”的版本；它只关闭移动布局这一层，避免把未验证的视觉改动说成已验收。
