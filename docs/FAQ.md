# CodePocket 常见问题（FAQ）

---

## 安装与运行

**Q：APK 为什么这么大（约 24MB / debug 43MB）？**
A：内置了 CPython 3.13 原生运行时（`libpython3.13.so`）+ 运行用标准库（纯 Python + C 扩展），同时打了 arm64-v8a 与 x86_64。0.0.32 剔除了 test/idlelib/turtledemo 等不参与运行的目录，所以 release 从约 31MB 降到约 24MB。装完即离线，之后不需要下载任何东西；本地模型权重按需下载，不打包进 APK。

**Q：安装时提示"未知来源"？**
A：在手机 设置 → 安全/隐私 → 允许安装未知来源应用（不同厂商路径不同）。

**Q：打开后一直"准备环境"？**
A：首次运行要解压标准库（约 1~5 秒），请稍等；若超过 30 秒仍未就绪，多半是 APK 被损坏或设备过于老旧，可重新安装试试。

**Q：支持哪些手机？**
A：Android 8.0+。Python 原生运行时同时提供 ARM64 与 x86_64；x86_64 可跑模拟器 / ChromeOS，JavaScript/Lua 与 ABI 无关。

## 写代码与运行

**Q：`import numpy` / `pandas` 报错？**
A：当前版本未预装第三方科学计算库。这是文档曾误导的已知问题，已如实修正。离线安装 wheel 的能力在 v1.1 路线图中。

**Q：运行 .java 文件？**
A：当前仅支持编辑与语法高亮，运行能力未开放（会给出明确提示）。JVM 集成在路线图中。

**Q：脚本用 `__file__` 报 NameError？**
A：该问题已在 v1.0.0 修复（引擎注入 `__file__` 等模块属性）。升级到最新 APK 即可。

**Q：运行超时被中断？**
A：设置里可调超时秒数（默认 120s）。死循环保护默认开启。

**Q：点停止后提示"已有程序在运行中"？**
A：旧进程正在收尾（通常 2~3 秒），稍候重试。若持续出现，说明脚本未响应中断（如阻塞在不可中断的系统调用），请重启 App。

**Q：`print("a", "b")` 输出顺序错乱？**
A：不应出现。引擎做行缓冲保证一行内输出顺序正确。如遇请提交 Issue 附复现。

## 功能

**Q：跳转到定义为什么找不到？**
A：它只扫描 `.py` 文件，上限 300 个文件、单文件 512KB；光标必须落在标识符上。`from utils import helper` 会优先匹配 `utils.py`，同名定义会全部列出。它不是 LSP，不做类型推断、继承解析或跨文件重命名。

**Q：调试时为什么看不到变量树/断点列表？**
A：0.0.28 接的是 CPython 标准库 `pdb`，属于终端式调试：用 `p locals()` 看变量、`w` 看栈、`b <行号>` 下断点。它不是图形化 DAP。调试期间目标程序的 `input()` 和 pdb 命令共用一个 stdin，交互式输入程序不建议调试。

**Q：关闭自动保存后，切文件会丢改动吗？**
A：不会。0.0.31 起，切文件、关 Tab、切项目前会弹出「保存并继续 / 不保存直接继续 / 取消」；只有明确选择放弃才会丢弃当前未保存文本。开启自动保存时仍会在切换前自动落盘。

**Q：保存到一半被杀进程，会把代码写坏吗？**
A：不会。0.0.31 起编辑器文件、工作区写入和 Agent 检查点都走「临时文件 + fsync + rename」；最坏情况是保留上一次完整版本，不会留下半个文件。单文件编辑上限 5MB，超过请用终端处理。

**Q：键盘弹出来时，输入框/按钮会被挡住吗？**
A：0.0.30 起所有面板都按「键盘上方可用高度」布局：标题、输入框和底部按钮固定，只有正文滚动；AI/Agent 的输入框放在 footer，终端按键条贴在键盘上方。输出面板的高度只在键盘期间临时夹取，不会改写你拖出来的高度。极少数不上报 IME inset 的自定义 ROM 仍可能覆盖，先收起键盘再滚动即可。

**Q：软键盘一弹出来，界面会突然变成横屏分栏吗？**
A：不会。0.0.30 的横竖屏判断改为系统方向，不再用「当前内容区宽高比」；键盘把高度压矮不会触发左右分栏。

**Q：终端能跑 vim / top 吗？**
A：可以。打开终端面板的「PTY 交互模式」后，底层是真实 `forkpty`，输出交给本地 xterm.js 渲染，所以 ANSI 颜色、光标定位、全屏重绘与滚动回看都能正常工作。软键盘没有的 Esc / Tab / Ctrl / 方向键用终端下方的补充键发送。日常简单命令仍可用默认的非 PTY 模式。

**Q：终端会联网或上传内容吗？**
A：不会。xterm.js 与页面资源都打包在 APK 的 `assets/terminal/` 里，本地 WebView 强制 `blockNetworkLoads` 并拦截外部跳转；终端只连接本机 `forkpty` 的 shell。

**Q：AI 助手怎么用？**
A：设置 → AI 助手 → 填写 OpenAI 兼容端点（Base URL / API Key / 模型名）。代码只会发送到你配置的端点，不配置则零联网。

**Q：Git 支持哪些操作？**
A：init / commit / push / pull / clone，基于 JGit，纯离线可用（push/pull/clone 需要网络与仓库凭证）。clone 只支持 HTTPS，从项目列表底部「从 Git 克隆」进入；目标目录必须不存在或为空。

**Q：怎么导入导出项目？**
A：通过系统文件选择器（SAF），无需存储权限。导入/导出的是项目 zip；导入拒绝绝对路径和 `../`，限制 10,000 条目 / 单文件 48MB / 解压 256MB，导出跳过 `.git`、`build`、`node_modules` 等目录并限制 256MB。

**Q：会话恢复？**
A：App 会记住上次打开的项目与文件，重启自动回到编辑现场。

## 开源与贡献

**Q：这是什么协议？**
A：Apache-2.0，代码完全开源可审查。

**Q：怎么参与贡献？**
A：见 [CONTRIBUTING.md](../CONTRIBUTING.md)。修 bug、写文档、提 Issue 都可以。

**Q：测试报告说 11/11 通过，为什么还有 bug？**
A：`tools/test_suite.py` 驱动的是早期 Web 原型（Pyodide 时代遗留），未覆盖原生引擎。原生引擎的自动化测试在路线图中（[ROADMAP.md](ROADMAP.md)）。
