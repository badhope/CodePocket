# CodePocket「口袋码」用户手册

> 版本：v0.0.29 · 适用：Android 8.0+（Python 支持 ARM64 / x86_64；JavaScript/Lua 任意 ABI）

---

## 1. 安装

1. 从 [Releases](https://gitcode.com/badhope/CodePocket/releases) 下载 release APK（双 ABI 约 31MB，debug 包约 49MB）；
2. 手机允许"安装未知来源应用"（不同厂商路径不同，一般在 设置 → 安全 → 未知来源）；
3. 安装后打开，首次运行会自动解压内置 Python 标准库（约 1~5 秒，之后秒开）。

> 提示：release 约 31MB，因为内置了完整 CPython 3.13 原生运行时（arm64 + x86_64）、标准库与本地推理桥。装完即离线，无需再下载任何东西；本地模型权重按需下载。

---

## 2. 符号大纲与定义跳转

按 `⌘K` 打开命令面板，输入「符号大纲」，会列出当前文件里的类和函数；点一行直接跳到对应行。支持 Python / Kotlin / Java / JavaScript / TypeScript / Lua。

### 2.1 跳转到定义（Python）

把光标停在函数名、类名或模块级变量上，命令面板搜「跳转到定义」。CodePocket 会扫描项目里的 `.py` 文件，列出同名定义的文件、行号和签名；点一条即打开对应文件并定位。

- 优先显示当前文件，其次优先 `from utils import helper` / `import pkg.utils` 对应的模块；
- 同名符号会全部列出，不自动替你选；
- 索引上限 300 个 `.py`、单文件 512KB。超过上限的文件不会进入索引，这是为了手机端不卡顿；
- 它是文本级索引，不是 LSP：不做类型推断、继承解析和重命名。光标必须落在标识符上。

## 3. 本地模型（可选）

命令面板搜「本地模型」，可下载 MiniCPM5-1B（约 656MB，6GB+ 设备）、MiniCPM5-2B（约 1.45GB，8GB+ 设备）或 Qwen3.5-2B（约 1.28GB，8GB+ 设备）。下载支持断点续传，完成后做 SHA-256 校验；在设置里开启「Agent 使用本地模型」后，Agent 不再发网络请求。

模型权重不打包进 APK，卸载 App 后系统会清掉外部目录里的模型文件。

### 3.1 Agent 计划模式

在 Agent 面板点「先计划：开」，Agent 会先列出步骤并等待批准；按「批准执行」后才开始读文件和改代码。设置页也能永久开启。计划模式会多一次模型调用，小模型或弱端点建议关闭。

### 3.2 Agent 历史会话

Agent 面板底部有「历史会话」。点开后列出最近 20 次任务的任务描述、时间、事件数和是否结束；点一条回放完整工具轨迹，也可以单独删除。记录只追加、不会自动重跑，适合排查「上次它到底改了哪几行」。会话文件保留最近 30 个。

## 5. 写代码

- **新建项目**：启动页 → 新建 → 选模板（基础 / 算法 / 数据处理 / 空项目）；
- **新建文件**：文件树右上 + → 输入文件名（`.py` / `.md` / `.html` 等）；
- **多文件 Tab**：点文件树里的文件即可打开/切换，Tab 可关闭；
- **编辑**：语法高亮、自动补全（Python 关键字/内置函数/当前文件符号）、自动闭合括号、自动换行、行号开关（设置里可关）；
- **字号**：双指捏合缩放；
- **查找替换**：顶栏搜索图标 → 输入关键词 → 逐个跳转/全局替换；
- **全局搜索**：跨当前项目所有文件搜索。

### 常用快捷键（软键盘模式）
- 快捷符号栏提供 26 个常用符号键；
- 运行中可使用方向键 / Tab 软键，发送给正在运行的程序。

## 6. 运行代码

1. 打开要运行的 `.py` 文件；
2. 点顶部 **▶ 运行**（或命令面板 → Run）；
3. 输出实时显示在底部面板；
4. 再次点 **■ 停止** 可中断运行（死循环也能停：先推 EOF 打断 `input()`，再发 KeyboardInterrupt）。

**命令行参数**：运行配置里可填，如 `--name "hello world"`（支持带引号）。

**交互输入**：程序运行到 `input()` 时，点输出面板的"点击输入"，输入后回车。

**超时保护**：设置里可调超时秒数（默认 120s）。超时自动中断，避免死循环耗电。

### 6.1 调试 Python（pdb）

1. 打开 `.py` 文件，点顶栏的 **虫子图标**（或命令面板搜「调试当前文件」）；
2. 程序会在第一行停住，输出面板出现 `(Pdb)` 提示符；
3. 输入 pdb 命令，或点输出面板上方的快捷条：

| 快捷条 | 等价命令 | 作用 |
|---|---|---|
| 继续 | `c` | 运行到下一个断点/结束 |
| 下一步 | `n` | 执行下一行，不进入函数 |
| 进入 | `s` | 进入下一行的函数 |
| 变量 | `p locals()` | 打印当前局部变量 |
| 栈 | `w` | 打印调用栈 |
| 断点 | `b <光标行>` | 在当前光标行下断点 |
| 退出 | `q` | 结束调试 |

也可以直接在输入行输入 `b 12`、`p x`、`pp x`、`l` 等标准 pdb 命令。

边界：这是终端式 pdb，不是图形化 DAP；没有变量树和断点列表。调试期间目标程序自己的 `input()` 与 pdb 命令共用一个 stdin，交互式输入程序不建议开调试。

### 6.2 终端与真实 PTY

命令面板搜「终端」打开终端面板。默认是轻量命令会话：每条命令独立执行，保留项目内 cwd，20 秒超时；适合 `ls`、`python -m pytest`、`git status`。

打开「PTY 交互模式（vim / top）」后切到原生 `forkpty` 后端，输出交给本地 xterm.js 终端模拟器：

- `isatty` 为真，`vim`、`top`、`less` 等依赖 tty 的程序可以正常显示颜色、光标与全屏界面；
- 点击终端区域唤起软键盘，输入直接进 shell；下方补充键提供 Esc / Tab / Ctrl-C / Ctrl-D / 方向键；
- 终端行列会随面板尺寸变化，自动通过 `TIOCSWINSZ` 同步给 shell；
- 关掉开关或关闭面板会结束 shell 会话；终端页离线加载，不访问网络。

## 7. 读结果

- **报错跳转**：输出里的 `line 12` / `main.py:12` 可直接点击，跳到对应行；
- **友好翻译**：20+ 高频错误（缩进、变量未定义、除零等）会自动翻译成人话；
- **Markdown / HTML 预览**：打开 `.md` / `.html` 文件 → 分屏实时预览；
- **PNG 图片**：脚本生成的图片文件点开直接看；
- **复制/分享输出**：输出面板底部按钮。

## 8. 管理项目

- **切换项目**：启动页列出所有项目，点选进入；长按可删除；
- **导入/导出**：通过系统文件选择器（SAF），不需要存储权限——导入 zip 或文件夹，导出项目 zip；
- **项目模板**：新建时选模板，自动生成目录结构。

---

## 9. Git（离线）

文件树 → 长按项目根 → Git：

- `init`：初始化仓库；
- `commit`：填写提交信息，提交全部变更；
- `push` / `pull`：需要仓库地址与凭证（仅支持 HTTPS 或本地仓库，离线定位）；
- 状态查看：变更文件列表。

> 基于 JGit（纯 Java），不依赖系统 git。

## 10. AI 助手（可选，BYOK）

默认关闭。打开后需自配 OpenAI 兼容端点：

- 设置 → AI 助手 → 填写 Base URL、API Key、模型名；
- 功能：解释当前文件、分析报错、生成单元测试；
- **隐私**：代码只会发送到你配置的端点；不配置则完全不联网。
- **项目规则**：项目根目录的 `AGENTS.md`、`.codepocket/rules.md` 会自动注入；
  `.codepocket/skills/*.md` 里的短技能说明也会按文件名顺序注入（最多 3 个）。
- **自定义命令**：`.codepocket/commands/*.md` 会出现在命令面板，选中后正文填入 Agent 输入框。
- **MCP**：设置里填 Streamable HTTP 端点并开启；只读工具自动执行，副作用工具仍要批准。
- **JS 插件**：设置里开启后，`.codepocket/plugins/*.js` 的 `run(input)` 会成为 Agent 工具，
  在 Rhino 沙箱运行，不能访问 Java/文件/网络；默认关闭。

## 12. 常见问题速查

| 问题 | 解答 |
|---|---|
| `import numpy` 报错？ | 未预装第三方科学库，见 [FAQ](FAQ.md) |
| 运行很慢？ | 首次运行解压标准库需几秒，之后秒开；可去设置调大超时 |
| 停止后无法再运行？ | 等 2~3 秒让旧进程收尾；若提示"已有程序在运行中"，稍候重试 |
| 中文乱码？ | 不应出现（Python 层 UTF-8 桥接）；如遇请提交 Issue |
| 能跑 Java 吗？ | 暂不支持，仅编辑高亮 |
| 手机提示"未知来源"？ | 设置里允许安装未知来源应用 |
